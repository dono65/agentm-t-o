# Conventions du projet

Avant toute modification de code, relisez ce résumé :

- Langue du code : identifiants en anglais, commentaires et documentation en
  français.
- Indentation : 2 espaces, sauf langage avec convention dominante (ex. Go :
  tabs).
- Nommage : `camelCase` pour les fonctions/variables, `PascalCase` pour les
  types/classes, `SCREAMING_SNAKE_CASE` pour les constantes.
- Tests : chaque nouveau comportement doit être couvert si un framework de
  test est configuré.
- Commits : Conventional Commits, message court à l'impératif.
