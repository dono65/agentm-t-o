# Conventions

(À compléter avec les conventions réelles du projet.)

## Code

- Identifiants en anglais, commentaires et docstrings en français.
- 2 espaces d'indentation par défaut.

## Commits

Format Conventional Commits :

```
type(scope): résumé court à l'impératif
```

Types : `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.

## Branches

- `main` : branche stable.
- `feature/<sujet>` : nouvelles fonctionnalités.
- `fix/<sujet>` : corrections.
